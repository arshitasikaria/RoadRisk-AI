# Power BI guide for RoadRisk AI

A `.pbix` file cannot be generated by code, so the Power BI report is built once in
**Power BI Desktop** (free) from the data exported by the app.

## 1. Load the data
1. Use `powerbi/roadrisk_powerbi_data.csv` (included), or log in as admin and download a fresh copy from
   **Admin > Power BI > Download export CSV**.
2. Power BI Desktop > **Get data > Text/CSV** > select the file > **Load**. Name the table `roadrisk`.
3. Check the types: `date` = Date, `year` and `month` = Whole number, `severity_weight` = Whole number.

Columns: date, year, month, road_name, corridor, area_type, road_type, road_condition, weather, time_of_day,
day_of_week, vehicle_type, cause, severity, severity_weight (Fatal 5, Serious 3, Minor 1).

## 2. Apply the dark theme (optional)
**View > Themes > Browse for themes** > choose `powerbi/RoadRisk_Dark_Theme.json`.

## 3. Measures (Modeling > New measure)
```
Accidents   = COUNTROWS(roadrisk)
Fatal       = CALCULATE([Accidents], roadrisk[severity] = "Fatal")
Serious     = CALCULATE([Accidents], roadrisk[severity] = "Serious")
Fatal %     = DIVIDE([Fatal], [Accidents])
Risk Index  = DIVIDE(SUM(roadrisk[severity_weight]), [Accidents] * 5) * 100
```

## 4. Suggested report page (Executive Overview)
| Visual | Fields |
|---|---|
| 4 cards | Accidents, Fatal, Fatal %, Risk Index |
| Stacked column chart | Axis: month; Legend: severity; Values: Accidents |
| Donut | Legend: weather; Values: Accidents |
| Bar chart | Axis: road_name (Top N = 10 by Risk Index); Values: Accidents |
| Line chart | Axis: year; Legend: severity; Values: Accidents |
| Clustered bar | Axis: cause; Values: Accidents |
| Slicers | corridor, year, area_type, time_of_day |

Tip: set the `corridor` slicer to **Pune-Solapur (NH-9)** by default to match the app dashboard.

## 5. Publish and embed (optional)
Save as `RoadRisk_AI.pbix`, publish, then **File > Embed report** and paste the URL into the
`POWERBI_EMBED_URL` setting (see README) to show it inside the app's Power BI page.
Take a screenshot of the finished report for Section 4.9 of the project report.
